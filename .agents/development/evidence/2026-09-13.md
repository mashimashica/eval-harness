## Specialist finding and bounded correction

Sol's separate review found default Skill and multi-agent context in unconfigured CLI probes. The first report
overstated the need for a separate process boundary: the standalone CLI's five default `.system` Skills were native
defaults, not inherited project development Skills. The controller's exact configured prompt probe removed them,
and Sol reviewed the correction once and retracted that broader claim. The app-bundled probe exposed a larger
catalog, so participant execution uses pinned standalone `@openai/codex@0.154.0` in `.tools/codex`.
Canonical temporary paths and `skills.config` entries ending in each default `SKILL.md` are necessary to disable
the five defaults. Features and project instruction discovery are disabled explicitly. At the selected Luna model,
the final executor prompt has no Skill/multi-agent/development markers. `.audit/executor-prompt.json` records the
rendered input; auth-only copying still reports ChatGPT, while the native sandbox denies auth.json and repo AGENTS.
This preserves the selected runtime, model and subscription billing route. No benchmark generation occurred before
these checks. Sol disclosed one unauthenticated `exec` probe that produced HTTP 401 and no model generation.

Claude `--safe-mode --restricted` preserves account auth while confining file tools and suppressing customizations.
It does not establish shell isolation if Bash is explicitly re-enabled. Test its file-tool route on GSM8K first;
any shell-enabled capability needs its own OS sandbox evidence. Selected Skill text must be explicitly staged and
read in safe mode because native Skill discovery is disabled there; document that distinction.

## Reuse and adaptation boundaries

The retained checkout was inspected before selecting the local route. These decisions concern the new harness,
not replacement or restoration of older fork implementations.

| Retained code | Decision and observed reason |
| --- | --- |
| `benchmarks/gsm8k/prepare.py` | Execute unchanged data preparation, including its existing answer fixes; verified 1,319 rows and source hash above. |
| `resources_servers/gdpval/data/example.jsonl`, `task_data.py` | Use retained public task/reference/rubric fields. Harness normalization keeps answer-bearing snapshots outside participants. |
| `responses_api_agents/stirrup_agent/tasks/gdpval.py` | Adapt its task/reference-file staging boundary; public files are acquired separately so preflight remains read-only. Native CLI workspaces replace container/server assumptions. |
| `responses_api_agents/codex_agent/app.py` | Adapt the existing JSONL CLI execution, temporary-home, timeout/process-group and stream-recording patterns. Its Gym provider config injects OPENAI_API_KEY and bypasses login; that path cannot be the required subscription route. |
| `responses_api_agents/claude_code_agent/app.py` | Adapt per-call configuration and stream usage collection. Its API environment, skip-permissions and optional bare/native-discovery behavior are incompatible with the measured account/isolation requirements. Exact pinned CLI probes determined the new confined invocation. |
| `nemo_gym/skills.py` | Preserve the Agent Skills frontmatter, content-hash provenance and file staging concepts. The local adapter stages only explicitly selected bodies/references; native discovery would expose ambient Skills in the actual probe. |
| `resources_servers/math_with_code`, retained GSM8K preparation | Adapt the final-answer/boxed convention into a bounded non-executing numeric/string grader. No arbitrary submission expression or candidate code execution. Formatting edge regressions and actual saved answers verify this local diagnostic grader; it is not an official score claim. |
| `resources_servers/gdpval/scoring.py`, `comparison.py` | Preserve rubric-scoring and anonymous A/B/tie concepts. Direct model client calls and office conversion/server setup are not mandatory. New CLI judges inspect immutable saved artifacts; both presentation orders are scheduled. |
| `nemo_gym/cli/`, upstream rollout/artifact handling | Retain upstream commands for upstream environments; the six requested local commands use the same task-to-artifact-to-judgment boundary, with new durable local journals for frozen resume and no API/server dependency. |

New responsibilities are the six-command contract, account-only runtime policy, independently frozen creation/application/
grading inputs, append-preserving journals, human entry and method-separated aggregation. The lightweight package
does not duplicate task acquisition or start the retained server graph merely to use its data.
