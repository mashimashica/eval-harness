# Eval Harness

The local, account-authenticated experiment CLI lives in this Python project. It reuses retained NeMo Gym benchmark
inputs without requiring model or resource servers.

See the [installation and usage guide](../fern/versions/latest/pages/get-started/eval-harness.mdx) for the six commands,
examples, runtime support and result interpretation. Development requirements, CLI specification and acceptance
records are maintained in [the shared development context](../.agents/development/README.md).
